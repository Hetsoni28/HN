# HN — Digital Product Studio

Production-ready starter for the HN company website.

## Stack
- Next.js 16+
- React 19+
- TypeScript
- Tailwind CSS 4
- Sanity CMS
- Framer Motion-ready component architecture

## Run
1. Copy `.env.example` to `.env.local`.
2. Add your Sanity project ID/dataset.
3. Install dependencies: `npm install`.
4. Start development: `npm run dev`.
5. Open `http://localhost:3000`.

## Sanity
Sanity Studio is mounted at `/studio` once the Sanity project values are configured. Schemas are in `sanity/schemaTypes`.

## Logo
The supplied HN master artwork is included in `public/hn-logo.svg` and `public/hn-logo.png`. The website version contains the HN monogram only: no circle and no tagline.
